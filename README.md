# Проект "Cерверная часть виджета банковских операций"

## Описание:

Виджет имеет возможность отображать операции клиента

## Установка:

+ Установите на свой компьютер GitHub.
+ Клонируйте репозиторий с GitHub  с помощью веб-URL.
```
https://github.com/Mullayanov/homework.git
```
+ Установите зависимости.
```
pip install -r requirements.txt
```

## Использование:

В текущем виде, программа запускается в модуле main.py:
Вводные данные внесены в модуль.

## Примеры использования функций:

+ Модуль masks
содержит функции для наложения масок на конфиденциальные данные:

**get_mask_card_number**

Принимает на вход номер карты и возвращает ее маску.

     7000792289606361 - входной аргумент
     7000 79** **** 6361 - выход функции

**get_mask_account**

Принимает на вход номер счета и возвращает его маску.

     73654108430135874305 - входной аргумент
     **4305 - выход функции

+ Модуль widget
содержит функции для работы с банковскими данными:

**mask_account_card**

Функция принимает один аргумент - строку, содержащую тип и номер карты или счета

     Visa Platinum 8990922113665229 - входной аргумент
     Visa Platinum 8990 92** **** 5229 - выход функции
     
**get_date**

Функция принимает на вход дату в формате: "2024-03-11T02:26:18.671407"
и возвращает строку с датой в формате "ДД.ММ.ГГГГ" ("11.03.2024").

      2024-03-11T02:26:18.671407 - входной аргумент
      11.03.2024 - выход функции

+ Модуль processing
содержит  функции для фильтрации и сортировки банковских операций:

**filter_by_state**

Фильтрует список операций по статусу выполнения (например по 'EXECUTED')

       ([{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
        {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
        {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
        {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}], 'CANCELED')  - входной аргумент
        
        [{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
         {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}] - выход функции
    

**sort_by_date**

Сортирует список операций по дате (по умолчанию - убывание)

      ([{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
       {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
       {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
       {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}], ) - входной аргумент
       
      [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
       {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, 
       {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
       {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}] - выход функции


**filter_by_currency**

Генератор, возвращающий итератор, который поочередно выдает транзакции, где валюта операции соответствует заданной

**transaction_descriptions**

Генератор который принимает список словарей с транзакциями и возвращает описание каждой операции по очереди.

     >>>"Перевод организации",
        "Перевод со счета на счет",
        "Перевод со счета на счет",
        "Перевод с карты на карту",
        "Перевод организации",
        "Перевод организации",


**card_number_generator**

Генератор номеров банковских карт. Создает номера в диапазоне от 0000 0000 0000 0001 до 9999 9999 9999 9999.

       4591 0417 5418 3113
       8951 8243 9309 0899
       7296 7303 5931 6270


## Тесты

+ Модуль test_masks
  содержит функции для теста маскировки номера карты и номера сечта с использоваием параметризации

+ Модуль test_widget
  содержит функции для теста маскировки нормера карты или счета, в зависимости, от вводных данных.
  Кроме того, в модуле тестируем приведение информации о дате в необходимый формат.

+ Модуль test_processing
  содержит тесты функции с помощью фикстуры, сортирующий операции по ключевымм параметрам, а так же функцию, сортирующую операции по датам
  по убыванию или возрастанию.

+ Модуль test_generators
  содержит тесты генераторов которые поочередно выдают транзакции по соответствующей валюте, выводят описание каждой 
  операции, а так же генерируют рандомные значения номеров карт.
